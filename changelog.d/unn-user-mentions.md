### Added

- Mention a server member from the channel composer's `@` list. Mentions name people by ID and notify the named member on desktop, in the browser, and through encrypted iOS and Android push. A click or tap opens the channel. Server mute, notification levels, and read state apply. Self-mentions and repeated updates stay quiet.
- Send a channel post addressed only to people without starting an agent task. Hosts without user mention support keep the agent picker.
